# Prompt Pack: WhatsApp Messages

Create excellent copy-ready WhatsApp action-card blocks.

The messages should be simple, warm, and useful for non-technical business owners.

Cover these business types:

- pre-launch custom gifts
- running custom gifts
- salon
- cafe
- clothing store
- local service

Every card should include:

- when to send it
- exact WhatsApp message
- why it works
- how to know it worked
- matching tags

Avoid sounding robotic, pushy, or like a corporate sales script.
