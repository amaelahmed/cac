# Prompt Pack: Competitor Cards

Create simple competitor/action cards for local businesses.

Cover:

- custom gift competitors
- cafes
- salons
- clothing stores
- local services

Each card should explain:

- what customers may choose instead
- what that option does well
- where this business can win
- message to use
- post idea
- how to know it worked

Keep the language simple. No business-school jargon.
