# Prompt Pack: Advanced Growth Plan

Create advanced growth action cards for businesses that already have the basics working.

Cover:

- custom gifts
- cafes
- salons
- clothing stores
- local services

Each card should include:

- what the user gets
- small preview
- why this helps
- first step
- how to know it worked
- tags

Do not make it feel like a locked report upsell. It should feel like genuinely useful next-level advice.
